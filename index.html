Project · 2026 · Desktop app

Agent Chat

A desktop chat app where I talk to my agents and Claude, and where nothing counts as my approval unless I really signed it.

  • Approvals are HMAC-SHA256 signed in the app's main process. Only a verifying line from me in the form approve T-xxxx action counts; agent, command-line and hand-typed lines are advice only.
  • A live Agents panel built from task files shows who is working, finished or blocked, and is labelled "unverified".
  • Served from a custom app:// protocol with Electron fuses set: no run-as-node, no inspect flags, asar integrity on. 44 unit tests pass, plus end-to-end runs of 20 checks on the Agents panel, 28 on the app and 9 on the built exe.
  • Security re-check of version 1.1.3: 0 High in both the Electron and the AI-agent review. The earlier round found 2 High in the AI-agent review: the open debug port is fixed, and the signing secret being readable by any process running as me is documented as a known limit.

Five security reviewer roles

Read-only sub-agents for my agent team. Each has a written test and a limit that says what it may never touch.

  • sql-security: injection, secrets and database permissions; never queries real data.
  • ai-agent-security: prompt injection, tool permissions and approval bypasses, tested only in a sandboxed copy.
